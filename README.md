# 🧩 Multi-Page React Website

A modern, fully **responsive multi-page website** built with **React**, **Redux Toolkit**, **TypeScript**, and **Tailwind CSS**.  
This project showcases a **dashboard-style interface**, blog pages, authentication forms, and a rich, animated user experience — ideal for portfolios and front-end skill demonstrations.

---

## 🌟 Overview

This project is designed to demonstrate **front-end development best practices** using React and Redux Toolkit.  
It includes multiple pages, a dark/light mode toggle with **localStorage persistence**, smooth animations with **Framer Motion** and **AOS**, and interactive UI elements using **Particles.js**.

> The website focuses on **design-first development**, emphasizing responsive layouts, animation, and modern UX patterns. While some features are purely UI (like Sign-in, Sign-up, and Dashboard), the project effectively highlights design and front-end implementation skills.

---

## 🧠 Key Features

- 🌓 **Dark / Light Mode** toggle with **localStorage persistence**
- 📱 Fully **responsive** across devices
- 🏠 **Home Page** – modern landing page
- ❌ **NotFound Page** – stylish 404 page
- 📝 **Blog / Articles Page** – includes **search** and **filtering** capabilities
- 🛠 **Dashboard Page** – designed layout for admin-style overview
- 🔑 **Sign-In / Sign-Up Pages** – UI design only, no backend logic
- ✨ **Animations** using **Framer Motion** and **AOS**
- 💨 **Interactive Particles.js background effects**
- 🗂 Modular project structure for maintainability and scalability

## ⚡ Getting Started

### 1️⃣ Clone the repository

```bash
git clone https://github.com/Alireza-404/Multi-Page-React-Website.git
```

### 2️⃣ Install dependencies

```bash
npm install
```

### 3️⃣ Run the project locally

```bash
npm run dev
```

Now open your browser at **http://localhost:5173** (or the port shown in the console).

## 🧩 How It Works

- Redux Toolkit manages global state across pages efficiently.
- LocalStorage stores the user's theme preference (dark/light mode).
- Framer Motion and AOS animate elements on scroll and interactions.
- Particles.js creates dynamic, eye-catching backgrounds.
- Search & filter functionality in blog page improves UX and interactivity.
- Pages like Sign-In, Sign-Up, Dashboard are design-only for portfolio showcase.
- The architecture is modular and scalable, making it easy to expand functionality or integrate a backend in the future.
